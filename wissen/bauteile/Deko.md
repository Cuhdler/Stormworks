Aus den Spieldaten erzeugt von `tools/bauteile_holen.py` - nicht von Hand ändern.

## Flag (Large) (`flag_large`)

*A large sized flagpole.*
The flag design can be set in the properties menu.

- Größe 1x7x1 Blöcke (voxel [0, 0, 0] .. [0, 6, 0]), Masse 3, Preis 100
- Werte: type=65

## Large Tyre (`tyre_large`)
